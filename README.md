# Prompt Atelier — AI 服装提示词资产工作台

本仓库用于 Prompt Atelier 的开发、测试与版本管理。

## 当前维护策略

- `main`：生产更新通道。未经完整验收，不向此分支发布候选版本。
- `release/v0.6.5-stabilization`：V0.6.5 稳定性隔离分支；仅用于源码同步、自动化测试和发布准备。
- 用户数据库、参考图片、API Key、个人配置均属于本地数据，不得提交到仓库或被程序更新覆盖。

## V1.0 路线

详见 [RELEASE_V1.0_PLAN.md](RELEASE_V1.0_PLAN.md)。

## 旧文件管理规则

旧版本源码、历史使用说明和旧启动脚本不直接混入当前发布包。为保留历史追溯能力，确认不再被当前程序、测试、更新清单或用户数据迁移引用后，优先移动到 `docs/archive/`；只有确认完全无引用、无恢复价值且已保留 Git 历史时，才删除仓库中的冗余副本。

## 发布门禁

正式发布前必须完成：
1. 当前分支源码与版本号一致；
2. 更新清单列出的文件均存在且 SHA-256 一致；
3. 自动化测试、静态检查和前端语法检查通过；
4. Windows 实机启动、关闭、重启、更新、失败回滚测试通过；
5. SQLite 数据库、参考图片、配置和凭据在更新前后保持完整；
6. 更新客户端指向与发布分支一致的更新源。

**注意：自动化测试通过不等于 Windows 实机验收通过。未完成 Windows 验收的版本不得标记为正式发布。**
