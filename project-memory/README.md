# Prompt Atelier 项目记忆中心

本目录是跨 ChatGPT 对话的项目接续入口。它保存经过确认的产品事实、技术决策和当前开发状态，不是聊天记录全文备份。

## 新对话读取顺序
1. PROJECT_MASTER.md：产品定位、固定需求与功能范围。
2. CURRENT_STATUS.md：当前版本、分支、提交、测试和发布状态。
3. TECHNICAL_DECISIONS.md：技术选择、数据边界、历史问题与修复原则。
4. TASK_QUEUE.md：未完成工作与验收条件。
5. CHAT_HANDOFF.md：最短接续摘要和下一步执行指令。

## 维护规则
- 以 GitHub 当前代码、CI 和更新清单为技术事实；以本目录确认记录为产品需求事实。
- 每完成一个独立开发阶段，更新状态、决策、任务队列和接续摘要。
- 不复制冗长聊天过程，只保留可复用决策、错误根因、修复和待办。
- 禁止写入 API Key、密码、用户数据库内容、私人配置或参考图片。
- 当前开发分支与生产分支隔离；未经完整验收不得修改生产分支。
- 测试未执行、正在运行、失败或跳过时必须如实标记。CI 通过不等于用户个人电脑验收通过。
