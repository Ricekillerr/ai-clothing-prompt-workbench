## 已知限制
- 浏览器感知哈希检索只是粗略近重复/视觉结构候选，不是语义服装识别。
- 英文提示词只保存和复用已有文本，不自动翻译。
- 原提示词中的 @图片编号需人工映射到资产库图片编号。
- 当前不承诺视频自动抽帧与语义分析。
- 需要真实 WAN 3.0、MiniMax H3、Seedance 2.5 生成任务验证模型指导价值。
