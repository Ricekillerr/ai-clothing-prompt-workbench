## 本轮安全审计新增修复
- 本地 HTTP API 新增 Host 白名单校验，只接受 127.0.0.1/localhost 且端口必须匹配当前服务，阻断 DNS rebinding Host 伪装。
- 浏览器请求携带 Origin 时必须与本机 loopback 来源和当前端口匹配；跨来源请求返回 403。
- JSON 写入接口只接受 application/json，拒绝简单表单 content-type；ZIP 恢复仍单独要求 application/zip。
- 新增 3 项 Windows 本地 API 安全回归测试，分别覆盖恶意 Host、跨来源 JSON 写入、简单表单 content-type。

## 本轮更新器事务安全审计新增修复
- 原更新器在回滚失败时静默吞掉异常，可能留下部分新旧文件混合状态。
- 现在逐项收集回滚与临时文件清理错误；回滚不完整时，日志明确标记“自动回滚未完整完成”，并保留原始程序备份目录供人工恢复，不再伪装为普通更新失败。
- 新增故障注入测试：模拟安装失败并再次模拟回滚失败，确认原始备份保留且日志指出恢复目录。

## 本轮备份恢复回滚审计新增修复
- 发现：完整备份恢复过程中若文件交换失败，旧逻辑会尝试回滚，但回滚动作再次失败时可能静默吞掉异常并删除临时恢复副本。
- 修复：逐项记录 SQLite、JSON、参考图片目录的回滚错误；若回滚不完整，保留恢复前副本目录和安全 ZIP，并在错误信息中明确两个恢复位置，提醒不得删除。
- 新增故障注入测试：分别验证恢复中途失败可正常回滚，以及数据库回滚再次失败时恢复副本保留、参考图片仍完整。

## 已知限制
- 浏览器感知哈希检索只是粗略近重复/视觉结构候选，不是语义服装识别。
- 英文提示词只保存和复用已有文本，不自动翻译。
- 原提示词中的 @图片编号需人工映射到资产库图片编号。
- 当前不承诺视频自动抽帧与语义分析。
- 需要真实 WAN 3.0、MiniMax H3、Seedance 2.5 生成任务验证模型指导价值。
