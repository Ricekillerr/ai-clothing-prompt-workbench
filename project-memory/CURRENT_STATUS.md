## 当前代码侧完成范围

- 本地 API：Host / Origin / Content-Type / Sec-Fetch-Site 校验，AI endpoint query/fragment 禁止。
- 来源扫描：符号链接与 junction 隔离、源目录边界、SHA-256 强制复扫、同来源扫描锁。
- AI 分析：原提示词/素材哈希校验，模型不得覆盖原文，保留首尾空格和换行。
- 人工入库：来源路径、哈希再次验证，复制图片可回滚，references 链接/junction 防护。
- 备份恢复：数据库、JSON、参考图打包；恢复独占操作锁，心跳保持响应，避免 watchdog 误杀。
- 媒体服务：仅六种栅格图片格式，拒绝 HTML、链接和目录联接，nosniff。
- 交互：智能检索乱序响应隔离，多单品穿搭逐件评分，避免跨单品属性误匹配。
- 批量删除/恢复：当前选择裁剪、JSON 去重、历史版本快照校验、50 条版本上限、Node UI 行为回归。
- 组合器：模块选择与结构说明选项隔离，草稿来源冻结，人工改稿标记明确。
- 列表：案例、模块、Prompt Vault、回收站分页；搜索重置页码；主资产和次级工作流可访问性基础。
- 视觉检索：63 位 pHash、亮度变化回归、仅已验证案例、每案例最佳图、阈值和并发隔离。
- 视觉检索输入参数：支持 0–63 的自定义 Hamming 距离阈值；超过 63 返回 400。
- 大库操作一致性：批量删除前规范化并去重 ID；资产库/模块库在删除、回收站恢复和历史版本恢复后统一返回默认第一页，避免旧筛选与页码组合把结果页置空。
- 提示词组合器：模块选择改为**多选标签 + 单选分组**，不再依赖 Ctrl/Cmd/Shift 多选；选中模块直接加入组合面板，同组模块互斥；组合区可重新排序、清空、编辑文本并复制中英提示词。
- 生成提示词结果：标题处同时提供“复制提示词”“复制 English”，不再隐藏辅助复制按钮；反馈入口、复制成功状态、生成时间和原始/组合提示词标识保持可见。
