# Prompt Atelier V0.5.0-A 集成与发布计划

## 当前状态
- V0.4.2 main 保持不变。
- 所有改动仅在 feature/v0.5.0-a-safe-storage 分支。
- SQLite 存储模块已接入开发分支主程序。
- 自动化回归测试在 Python 3.11、3.12、3.13 均通过。

## 重要兼容性约束：分两步升级
V0.4.2 现有运行程序的更新白名单不包含 storage.py。不能直接发布一个包含 storage.py 的 V0.5.0 更新包，否则旧版客户端会在下载阶段拒绝它。

因此发布必须分两步：
1. V0.4.3 兼容引导更新：仅更新主程序更新白名单、updater 白名单及更新机制；不切换数据库，不改变现有 JSON 数据读写。
2. V0.5.0 正式升级：在确认客户端已具备下载 storage.py 的能力后，再一起更新主程序、storage.py、updater.py、版本说明及清单。

## V0.5.0 数据迁移安全条件
- 迁移前完整解析并校验 JSON；原文件永不被覆盖或删除。
- JSON 无法解析、字段结构不正确、记录 ID 缺失或重复时，停止启动迁移并保留源文件。
- SQLite 初始化完成后才允许读取数据。
- 读库失败时不得返回空列表并继续写入。
- 迁移后核对案例数、模块数及记录 ID；只有核对通过才允许启用数据库读写。
- references 图片目录保持原位置，不复制、不移动、不删除。
- 用户数据目录仍为 %USERPROFILE%\\AI_Prompt_Asset_Workbench。

## 尚未完成的验收
- 读取真实 V0.4.2 JSON 样本并进行字段兼容性测试。
- Windows Python 3.15 启动、迁移和重启测试。
- UI 创建、编辑、删除案例及模块后持久化测试。
- 图片上传、预览及原有图片引用测试。
- 数据库备份恢复测试。
- 更新器两阶段升级测试。
- 只有全部通过才合并 main 并生成正式更新清单。

## 暂不实施
- 不修改生产 main。
- 不发布 V0.5.0。
- 不删除旧 JSON。
- 不自动移动用户原始素材。
- 不启用 Runninghub 或 AI API。
