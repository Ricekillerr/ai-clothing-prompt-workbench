# V0.8 Conservative Conflict Detection — Revalidation

## Changes
- Removed material exclusivity from conflict detection. Garments can legitimately combine nylon, cotton, wool, leather trims, and other materials; a query mentioning one material must not automatically contradict a mixed-material case.
- Color conflicts are now considered only when exactly one canonical color is requested and exactly one canonical color is present in structured `color` / `color_details` fields.
- Multi-color queries and multi-color records are not automatically rejected.
- English color aliases use word boundaries to reduce accidental substring matches.
- Free-form prompt body text is not used as the source of truth for color contradiction.

## Test evidence
The first regression run exposed a fixture mistake: the test named "unstructured body text" still had a structured black color field, so the conflict was correctly detected. The fixture was corrected to omit structured color fields and isolate the intended condition.

## Safety boundaries
- Material blends are not treated as contradictions.
- Multi-color garments are not auto-rejected.
- This detector only uses structured color fields; it does not infer colors from images.
- No user database, reference images, or local configuration are modified.
