# V0.8 Conflict-Aware Retrieval Progress — 2026-11-12

## Implemented
The case matcher now detects explicit contradictions for selected mutually exclusive attributes:
- Colors: black, white, red, blue/navy, green, brown, grey, beige.
- Materials: leather, corduroy, nylon, wool, cotton, denim.

When a query requests one value and the stored case text explicitly contains another value in the same exclusive dimension, `find_case_conflicts()` reports the conflict. `rank_case_matches()` excludes conflicted cases by default. A caller can set `include_conflicts=True` to retrieve them for manual review. Each returned item includes a `conflicts` array.

This is conservative lexical conflict detection, not visual understanding. It only catches values explicitly represented in stored text. It does not infer garment color or material from image pixels, and it must not be described as a comprehensive contradiction engine.
