## 桌面交互与截图清单

在同一隔离 VM 的交互桌面，使用独立测试资料启动 `PromptAtelier.exe`，保留自动化操作日志和带时间戳的截图；至少记录首页、案例列表和详情、搜索前后、导航切换、图片和视频展示、编辑保存、关闭和重启后的数据。检查白屏、黑屏、乱码、错位、按钮反馈、后台浏览器和服务进程是否退出。截图、日志不得包含真实案例、密钥、用户路径或其他隐私。

当前源码静态检查发现，`ai_prompt_workbench.py` 的 `MEDIA_MIME_TYPES` 仅列图片类型，而 `index.html` 的案例素材区列出素材路径、未发现视频播放控件。已实现的视频导入与解码测试不能证明桌面视频能够播放；此项须在真实 UI 测试中明确验证，缺失即记录为未通过，不能以文件名出现代替视频展示验收。

建议的交互顺序：确认页面标题和导航；新增包含中文提示词及图片的临时案例并保存；搜索唯一关键词、打开详情；切换提示词模块及单品栏目再返回；通过已授权临时目录扫描并导入测试视频；检查图片显示和视频展示；编辑案例并确认重启后仍能读取；关闭全部页面后等待心跳退出并确认相关服务和子进程结束。每步记录预期、观察结果和截图编号。任何未执行项标为未执行，不得以 HTTP 成功推断 UI 成功。
