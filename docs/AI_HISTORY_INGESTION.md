# Prompt Atelier V0.5.0：历史案例 AI 分析流程

## 当前能力

1. 指定本地文件夹，递归扫描 TXT、MD、JSON、图片和视频文件。
2. 原始文件只读；扫描器不移动、不重命名、不删除原始文件。
3. 基于文件名和目录信息生成提示词—素材关联候选。候选只是建议，不代表事实。
4. 用户选择一组候选后，可调用 OpenAI 兼容的 Chat Completions API 分析。
5. AI 分析结果保存在本地 SQLite 的 `ai_analyses` 表，状态为 `review`。
6. 用户点击“确认并入库”后，才创建正式案例；点击“拒绝”不会创建案例。

## AI 服务配置

- API 地址：默认 `https://api.openai.com/v1`，程序自动补全 `/chat/completions`。
- 模型名称：由用户填写，例如服务商支持的视觉模型。
- API Key：每次分析请求临时提交，只在内存和本次 HTTPS/API 请求中使用；不写入 JSON、SQLite、配置文件或日志。
- 本地工作台只监听 `127.0.0.1`。
- 发送前会重新计算源文件 SHA-256，若文件自扫描后变化则拒绝分析，要求重新扫描。

## 已知边界

- 图片支持 PNG、JPG、JPEG、WEBP、GIF；单张不超过 8MB。
- 提示词支持 TXT、MD、JSON；单个文件不超过 1MB。
- 视频目前只把文件名和“未抽帧”说明交给模型，不会声称理解视频画面。后续需单独增加安全抽帧模块。
- 当前 AI 适配器使用 OpenAI 兼容的 Chat Completions 格式及 JSON 输出模式；非兼容服务暂不支持。
- AI 输出是建议，不是事实。用户确认前不会写入正式案例库。
- 第一版不会自动推断视频时间轴、动作细节或提示词与画面是否完全一致。

## 隐私与成本

历史文件仅在用户点击“AI 分析此组合”后才会发送给用户配置的 AI 服务。调用可能产生第三方 API 费用；用户应确认服务商、数据政策和费用后再使用。没有填写 API Key 时，纯本地扫描、去重和文件名关联仍可使用。
